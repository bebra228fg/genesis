# MEMENTO — Make the Invisible Visible

Личный веб-дневник, который превращает текст о дне, фотографии и музыку в анимированное художественное воспоминание формата 9:16 и сохраняет его в отдельную «папку дня».

## Возможности
- **Русскоязычный анализ текста (`js/moodEngine.js`):** извлечение 5 непрерывных параметров атмосферы (`valence`, `energy`, `nostalgia`, `calm`, `tension`) с учётом отрицаний и модификаторов, времени суток и сезона.
- **Анализ фотографий (`js/photoEngine.js`):** алгоритм median-cut на Canvas извлекает 3 доминирующих цвета, светлоту и теплоту снимков.
- **Честная работа с музыкой (`js/musicEngine.js`):** воспроизведение через Spotify/YouTube embed или локальный `<audio>`; для загруженных аудиофайлов выполняется реальный анализ первых 20 секунд через Web Audio API (RMS и яркость).
- **Единая визуальная система (`js/artEngine.js`, `js/sceneRenderer.js`):** 5 художественных техник (Клод Моне, Василий Кандинский, аналоговая плёнка, японский минимализм, редакционный коллаж) внутри общей дневниковой рамки 9:16.
- **Объяснимость:** панель «Почему этот день выглядит так?» показывает вклад каждого источника (текст, фото, музыка).
- **Озвучка (`js/voiceEngine.js`) и архив (`js/storage.js`):** синтез речи под атмосферу дня и локальное сохранение папок и медиа в IndexedDB.

## Локальный запуск
Проект использует ES-модули (`type="module"`), поэтому запускается через любой локальный HTTP-сервер (например, VS Code Live Server или `python -m http.server 8000`) либо напрямую через GitHub Pages.
